SETTING NEW LOCATION: Right click on the new location or type in an address at 
        the top of the window.

ZOOM: Click the zoom level button 1-7 or zoom in/out buttons at top of window.
        or use the scroll wheel.

REFRESH: Data should update automatically.  However, some networks may cut out
        causing a lag in the data.  If you suspect there is a lag in the data
        you can press the refresh button in the upper left to force refresh
        all the data displayed on the map.

MAP OVERLAYS:  Use the check-boxes at the bottom of the screen to turn layers
        on/off.

VIEWING RADAR PRODUCTS:  Use the radar combo box in bottom right corner.  If
        you load a radar loop like Storm Total Precip you can sample the 
        rainfall amounts by turning the loop off (Click the Loop checkbox).
        Then when the loop stops you can sample the radar imagery using the
        mouse and moving it over portions of the radar imagery.  This works
        for most of the radar products.

UPDATES:  You should use RunWeatherMonitor.jar to launch the application. 
        RunWeatherMonitor.jar has a built-in check for updates.  If there is
        an update available the next time you launch RunWeatherMonitor.jar it
        will ask if you want to install the update.  Click Yes and it will
        install the update and launch WeatherMonitor.

OTHER FEATURES: The application is location specific.  So any new watches, 
        warnings or advisories that come in that affect your location...an 
        alert will sound and a table will pop up in the upper left corner of
        the window listing all the products in effect for your location.

        You can click or mouse over a lot of the features on the map.  If you
        mouse over the temperatures on the map you can get more details of 
        the observation.  If you left click while the observation sample is
        visible...you can open a new dialog box that will list 24 hours of 
        observations for that site.

        If you click on a watch, warning or advisory you can read it.
 
        If you click on the forecast icons...you can read the forecast.

        Clicking on the last forecast icon at the bottom will give you the 
        remainder of the forecast.

        The lightning bolt icon in the upper left corner will open the SPC
        Convective Outlooks.

        The CPU icon in the upper left corner enable/disables hardware graphics
        acceleration.  Some PC's do and some don't work with this enabled.
        But, what it does is allows the radar to loop smoother and faster.
        Enabling and disabling this feature require restarting the application. 
      
        All the settings are accessed in the button full of lines in the upper
        left corner of the application window.  The most common thing to do in
        the settings is to set your location and your favorite locations.  A 
        handy tip/feature is to type your address first the hit <Enter> and 
        the lat/lon will fill in for you. If you want the application location
        and size to always be the same...press the Use Current button to fill
        in the window location parameters.  You can also change colors of map
        features, set font sizes, loop speed and other preferences.

        NOTE: The loop speed will max at 2 frames per second regardless of
              what you set the loop speed to if you don't enable hardware
              graphics acceleration via the CPU icon button in the upper left
              corner of the main application window.
